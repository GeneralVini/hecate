## Uso recomendado

### `logo-horizontal.png`

Topbar, login, README, apresentações e cabeçalhos institucionais.

### `logo-vertical.png`

Capas, splash, materiais verticais e páginas institucionais.

### `symbol.png`

Sidebar recolhida, avatar do produto, loader e componentes compactos.

### Favicons

Usar o tamanho adequado para browser, atalhos e manifest/PWA.

### `login-background.jpg`

É **somente background**. Não deve conter formulário, campos de usuário/senha ou botão desenhado.

O formulário real deve ser HTML/Yii2/Bootstrap e ocupar a área de escape visual reservada na composição.

### `dashboard-background.jpg`

Aplicar com baixa intensidade, overlay ou opacidade reduzida. Não pode prejudicar a leitura de cards, tabelas, alertas ou métricas.

### `hecate-hero.jpg`

Uso institucional, onboarding e apresentação da solução. Não usar como fundo permanente de telas operacionais densas.

## Direção visual

A identidade usa:

- azul-marinho;
- azul institucional;
- dourado;
- branco/tons neutros;
- Hécate;
- chave;
- tocha;
- lua tríplice;
- caminhos/portais;
- documentos, impressão, controle e monitoramento.

Evitar:

- `APP-PRINT`;
- navio como elemento principal;
- cães como elemento central;
- excesso de fantasia;
- excesso de texto dentro das imagens;
- mockups de login embutidos em backgrounds.

Consulte `docs/IDENTIDADE-VISUAL.md` para as regras completas de interface e branding.
