# Identidade visual HECATE

Nome do produto: **HECATE**.

Descrição: **Plataforma Institucional de Governança e Controle de Impressão**.

Paleta-base: azul-marinho, dourado, branco e tons neutros. Elementos conceituais: Hécate, chave, tocha, lua tríplice, caminhos/limiares, documentos, controle e monitoramento.

O layout da aplicação segue admin dashboard com menu lateral retrátil, topbar, navbar contextual, conteúdo central e footerbar.

O background de login deve ser uma imagem pura, sem campos desenhados, mantendo Hécate em uma lateral e área de escape limpa na outra para o formulário HTML real.

Assets binários são mantidos fora do repositório até que o canal de upload de binários esteja disponível. SVGs e demais assets textuais podem ser versionados normalmente.
